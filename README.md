# Youssef Ait Addi — Portfolio

Personal portfolio built with Next.js, TypeScript and Tailwind CSS, featuring three projects:

- **kelus** — a local-first study app that turns a student's own notes into an adaptive recall plan.
- **Digi Moqef** — a home-services booking studio site (plumbing, electrical, AC, painting, handyman, cleaning).
- **Caffeine** — a multi-page specialty coffee shop site.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

Next.js 16 (App Router) · TypeScript · Tailwind CSS v4
